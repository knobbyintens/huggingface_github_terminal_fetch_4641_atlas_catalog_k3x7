# Spot Price Archive

## Dataset Card

- **Slug:** `spot-price-archive`
- **License:** ODbL-1.0
- **Source:** External - Iberian Energy Registry
- **Maintainer:** Market Data Team
- **Records:** 2,310,884

## Description

Hourly day-ahead electricity spot prices for the Iberian market, consolidated from the regional grid operator registry.
